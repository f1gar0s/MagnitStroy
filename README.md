# МагнитСтрой — сайт строительного магазина

Интернет-магазин в духе DNS: верхняя строка с выбором магазина, оранжевая кнопка «Каталог» с выпадающим меню, большая строка поиска с подсказками, баннеры, плитки категорий, карусели товаров, каталог с фильтрами, карточка товара с наличием по магазинам, корзина и оформление заказа.

Сайт статический: HTML + CSS + JavaScript, без сборки и без сервера. Чтобы открыть его, откройте `index.html` в браузере. Можно сразу выложить на GitHub Pages: Settings → Pages → ветка `main`.

## Две торговые точки
- Покупатель выбирает свой магазин в верхней строке. Выбор запоминается.
- На каждой карточке видно наличие: «в 2 магазинах», «только в магазине…», «под заказ».
- На странице товара показаны остатки в каждом магазине.
- В каталоге есть фильтр «В наличии в магазине…».
- В корзине при самовывозе сайт проверяет, есть ли все товары в выбранном магазине.

## Структура
```
index.html        — каркас: шапка, меню, подвал, нижнее меню на телефоне
css/style.css     — все стили и адаптив
js/data.js        — МАГАЗИНЫ, КАТЕГОРИИ, ТОВАРЫ, БАННЕРЫ (правится здесь)
js/icons.js       — SVG-иконки
js/app.js         — страницы, корзина, фильтры, поиск, заказ
```

## Что заменить перед запуском
1. `js/data.js` → `SHOP` и `STORES`: город, реальные адреса, телефоны, часы работы.
2. `js/data.js` → `PRODUCTS`: ваш ассортимент, цены и остатки (`stock: [магазин1, магазин2]`). Сейчас там демонстрационные данные.
3. Фото товаров: сейчас вместо фото стоят иконки категорий. Чтобы показать фото, добавьте товару поле `img` и выводите его в функции `productImg()` в `app.js`.
4. Отправка заказов: сейчас заказ сохраняется только в браузере покупателя (см. `// TODO` в `initCheckout()` в `app.js`). Подключите отправку в Telegram-бот, на почту (например, через Formspree) или в свою CRM.
